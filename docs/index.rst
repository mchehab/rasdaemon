RAS Daemon documentation
========================

rasdaemon monitors and records Linux kernel Reliability, Availability and
Serviceability events. Start with the overview, or go directly to the build
and installation instructions.

Product quality targets, their verification evidence, and the maturity roadmap
are collected in :doc:`development-principles`.

This documentation describes rasdaemon |release|.
